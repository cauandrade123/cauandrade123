## Por onde começar

**[backend-barbershop](https://github.com/cauandrade123/backend-barbershop)**: API de agendamento em Node.js, Express e MySQL. O ponto mais interessante é o controle de concorrência: travas `GET_LOCK` por horário e por agendamento impedem que duas pessoas reservem o mesmo horário. Tem autenticação com JWT e bcrypt, validação centralizada, testes e ambiente local com Docker.

**[doctors-health-api](https://github.com/cauandrade123/doctors-health-api)**: API do meu TCC, feito em equipe. Cuidei do deploy na AWS: API em EC2 com PM2, banco MySQL migrado para RDS e front-end no Amplify.
